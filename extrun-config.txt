# =====================================================================
# ExtRun 設定ファイル（サンプル）
#
# extrun.exe と同じフォルダに extrun-config.txt という名前で置きます
# （文字コードは UTF-8）。
#
# これはそのまま使える最小限の見本です。ここに書き足していってください。
# 書き足したら extrun.exe --check で書き方を確かめられます。
#
#   書式をひととおり知りたい → extrun-config-format.md（仕様）
#   実際のアプリの設定例     → extrun-recipes.md（レシピ集）
# =====================================================================


# --- 項目の書き方 ----------------------------------------------------
# 1 行が 1 項目です。3 つの欄を | で区切って書きます。
#
#   メニューに出る名前 | 起動するアプリ | 渡す引数
#
# 引数の $p は「選んだファイルのフルパス」に置き換わります。
# 引数の欄ごと省くと $p を渡したことになるので、たいていは 2 つで足ります。
#
# # で始まる行はコメントです。読み飛ばされます。


# --- パスの別名 ------------------------------------------------------
# @名前 = 値 と書いておくと、以降 @名前 と書けます。
# アプリを入れ直して場所が変わっても、直すのは 1 行だけで済みます。
#
# %SystemRoot% のような環境変数は、パスの欄でだけ展開されます。
# Windows が C: 以外に入っている環境でも正しく指せます。

@win = %SystemRoot%
@sys = @win\System32


# --- 画像 ------------------------------------------------------------
# [ ] だけの行は「ここから下はこの拡張子のときに出す」という見出しです。
# 拡張子は先頭のドットを付けて、空白で区切って並べます。

[.png .jpg .jpeg .gif .bmp]

既定のアプリで開く | @win\explorer.exe | $p
プログラムから開く | @sys\rundll32.exe | shell32.dll,OpenAs_RunDLL $p


# --- テキスト --------------------------------------------------------

[.txt .md .log .csv .ini .json .xml]

メモ帳で開く | @win\notepad.exe


# --- すべてのファイル ------------------------------------------------
# file は「フォルダ以外のすべて」、folder は「フォルダ」を指します。
# この 2 つだけは拡張子ではないのでドットが要りません。

[file]

親フォルダを開いて選択 | @win\explorer.exe | /select,$p


# --- フォルダ --------------------------------------------------------

[folder]

エクスプローラで開く | @win\explorer.exe | $p

# 引数の欄を空にする（行末を | で終える）と、引数なしで起動します。
# 次の行の :dir は「どのフォルダで動かすか」の指定です。
コマンドプロンプトで開く | @sys\cmd.exe |
 :dir $p
