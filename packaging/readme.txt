 2. 動作環境
-----------------------------------------------------------------------

 Windows 10（バージョン 1703 以降）/ Windows 11 の 64bit 版

 ※ 高 DPI の画面に対応するための API（Per-Monitor V2）が 1703 以降
    でしか使えないためです。

 ※ レシピ集の tar.exe を使う例だけは、tar.exe が標準で入った
    1803 以降が必要です。

 3. 導入手順
-----------------------------------------------------------------------

 1. このフォルダごと、好きな場所に置く（例: C:\Tools\extrun\ ）

    後から移動すると登録先（ファイラやショートカット等）からの参照が
    ずれるので、先に置き場所を決めておくことをおすすめします。

 2. extrun-config.sample.txt をコピーして extrun-config.txt に変える

    extrun.exe は、自分と同じフォルダにある
    extrun-config.txt しか読みません。

 3. 任意で「6. エクスプローラから使う」の登録を行う

 サンプル設定は Windows 標準のコマンドだけで動くので、この時点で
 そのまま試せます。読み通せる最小限の内容にしてあるので、まず開いて
 中身を眺めてから、お使いのアプリを書き足していってください。

 追加のインストールなしで使える一歩進んだ例は、extrun-recipes.md の
 「3. Windows 標準コマンドだけでできること」にまとめてあります。

 4. 使い方
-----------------------------------------------------------------------

 extrun.exe にファイルやフォルダのパスを引数で渡すとメニューが出ます。
 渡したファイルの種類に応じた項目だけが表示されます。

 複数のファイルをまとめて渡すこともできます。その場合、既定では
 ファイルごとに 1 つずつアプリが起動します。設定側で「+」を付けた
 項目だけは、すべてのファイルがまとめて 1 つのアプリに渡されます。

 1 つずつ起動する項目に「:delay」を書くと、起動と起動のあいだに
 待ち時間が入ります。同時に叩くと取りこぼすアプリ（2 つ目以降を
 1 つ目のウィンドウに渡す作りのビューアなど）に効きます。待ち時間の
 合計が長いときは、一時停止と中止のできるダイアログが出ます。
 中止できるのはまだ起動していないぶんだけで、起動済みのアプリは
 止まりません。

 「:wait」を書くと、起動したアプリが終了してから次の 1 つを起動
 します。処理が終わると自分で終了するツールはもちろん、開いて手で
 操作してから閉じるアプリでも効くので、「1 枚開く → 手で直す →
 閉じると次の 1 枚が開く」という使い方ができます。こちらは待ち時間
 が読めないので、進行状況のダイアログが必ず出ます。
 なお、起動したあとすぐ終了して処理を別のプロセスに渡すアプリ
 （すでに開いているウィンドウに渡す作りのもの）では待ちません。

 「:when single」「:when multi」を書くと、選んだファイルの数に
 よって項目を出し分けられます。名前を 1 つずつ付け直す項目や、
 連番を振る項目のように、選んだ数で意味が変わるものを隠せます。

 実行する前に値を尋ねる入力欄も置けます（設定側に $?{...} と
 書きます）。決まった選択肢から選ばせたいときは $?list{...} を
 使うと、打ち込むのではなく一覧から選ぶ形になります。
 複数のファイルを渡したときは $i が何番目か、$c が総数になるので、
 出力するファイル名に連番を入れられます。$i は総数の桁に合わせて
 ゼロで埋まるので、できたファイルの並び順が崩れません。

 一度にたくさんのファイルを渡したときは、起動する前に確認の
 ダイアログが出ます。既定では 20 個を超えたときで、対象の一覧を
 見てから実行するか決められます。数を変えるには設定ファイルの
 [extrun] に confirm-over = 50 のように書きます（off で出なくなり
 ます）。「+」を付けた項目は何個渡しても起動が 1 つなので出ません。

 メニューの項目名に & を書いておくと、次の 1 文字がアクセスキーに
 なります。メニューが出ているあいだにそのキーを押すと実行できます。
 （下線が見えないときは Alt キーを押してください）

 ● オプション

   extrun.exe --check     設定ファイルを検証する
   extrun.exe --version   バージョンを表示する
   extrun.exe --help      使い方を表示する

   extrun.exe --preview <パス>
                          そのファイルに対して実際に起動される
                          コマンドラインを、起動せずに表示する

 次の 3 つは、設定ファイルに書いた既定値を呼び出しごとに上書きします。
 右クリックからはカーソル位置、ホットキーからはウィンドウ中央、
 といった使い分けができます。

   --at <位置>        メニューを出す位置
                        cursor  マウスカーソルの位置（既定）
                        window  前面ウィンドウの中央
                        screen  画面の中央
                        X,Y     画面座標を直接指定（例 100,200）
   --select-first     先頭の項目を選択した状態で開く
   --no-select-first  選択しない状態で開く

 読み込む設定ファイルは --config で切り替えられます。上の 3 つと違い、
 --check や --preview と一緒でも使えます。

   --config <パス>    読み込む設定ファイルを指定する
                      （相対パスはカレントディレクトリ基準）

   例）extrun.exe --check --config D:\test\extrun-config.txt

 5. 設定ファイル
-----------------------------------------------------------------------

 extrun-config.txt に設定を書いて利用します。

   ・はじめの一歩        →  extrun-config.sample.txt（コメント付き）
   ・書式の完全な仕様    →  extrun-config-format.md
   ・実用的な設定例      →  extrun-recipes.md
                             （3 章は追加インストール不要）

 ● 書き換えたら確認する

 extrun.exe のあるフォルダで extrun.exe --check を実行すると、
 書式の誤り、別名の重複や未定義、見つからない実行ファイル、
 アクセスキーの重複などを行番号付きで一覧表示します。

 ● 何が起動されるか確かめる

 extrun.exe --preview <パス> を実行すると、そのファイルに対して
 メニューに出る項目と、実際に起動されるコマンドラインを、
 起動せずに一覧表示します。

   extrun.exe --preview "C:\photo\a.jpg"

 引数は 1 つ 1 行で表示されます。引用符で囲み忘れて空白のところで
 割れてしまった引数は、これで見つけられます。

 6. 【任意】エクスプローラから使う
-----------------------------------------------------------------------

 このアプリはファイラ等からの利用を想定していますが、
 下記の方法でエクスプローラからも利用できます。

 ● 「送る」メニューに登録する

   1. エクスプローラのアドレスバーに shell:sendto と入力
   2. 開いたフォルダに extrun.exe のショートカットを置く

   右クリック →「送る」→ ExtRun で実行できます。
   選んだファイルは何個でも 1 つの ExtRun にまとめて渡されるので、
   設定側で「+」を付けた項目もそのまま使えます。

   Windows 11 では「送る」は右クリックメニューの
   「その他のオプションを表示」の中にあります
   （Shift キーを押しながら右クリックすると直接開けます）。

   ショートカットは何個でも置けます。ショートカットのプロパティで
   「リンク先」の末尾にオプションを足しておくと、呼び出し方ごとに
   メニューの出方を変えられます。

     ExtRun.lnk         "C:\Tools\extrun\extrun.exe"
     ExtRun (中央).lnk  "C:\Tools\extrun\extrun.exe" --at screen

 ● 右クリックメニューに直接足す方法はおすすめしません

   レジストリを編集して右クリックメニューに項目を足す方法もあり、
   ver. 1.1.0 までは登録用のファイルを同梱していましたが、
   Windows の仕様上の制限があるため取りやめました。

   ver. 1.1.0 までの registry\extrun-add.reg で登録済みの場合は、
   その zip に入っていた registry\extrun-remove.reg で解除できます。
   手元に無いときは PowerShell で次の 2 行を実行してください。

     Remove-Item -LiteralPath 'HKCU:\Software\Classes\*\shell\ExtRun' -Recurse
     Remove-Item -LiteralPath 'HKCU:\Software\Classes\Directory\shell\ExtRun' -Recurse

   -LiteralPath を付けるのは、* を PowerShell がワイルドカードとして
   解釈しないようにするためです。

 ● ホットキーから呼び出す

   AutoHotkey で「エクスプローラで選択中のファイルにメニューを出す」
   スクリプトを extrun-recipes.md の付録に載せてあります。

 7. 安全にお使いいただくために
-----------------------------------------------------------------------

 ExtRun は、設定ファイルに書かれたコマンドをそのまま実行します。
 設定ファイルは、実行できるスクリプトと同じものだとお考えください。

 ● 出所の分からない extrun-config.txt をそのまま使わないでください。
    中身を読んでから使ってください。

 ● ExtRun のフォルダは、書き込み権限が管理された場所に置いてください。
    （C:\Tools\extrun\ など。誰でも書き込めるフォルダに置くと、
      設定ファイルを他から書き換えられる可能性があります）

 ExtRun 自身は管理者権限を必要とせず、レジストリの編集も、
 設定ファイルの読み込み以外のファイルの読み書きも行いません。

 8. うまくいかないときは
-----------------------------------------------------------------------

 ● 右クリックしても「送る」に ExtRun が出ない
    → Windows 11 では「送る」は「その他のオプションを表示」の中に
       入っています（Shift + 右クリックでも直接開けます）。
    → shell:sendto のフォルダにショートカットを置きましたか。
    → ExtRun のフォルダを後から移動すると、ショートカットのリンク先が
       切れます。ショートカットを作り直してください。

 ● メニューが出ずにエラーが表示される
    → extrun-config.txt が extrun.exe と同じフォルダにありますか
       （extrun-config.sample.txt のままになっていませんか）。
    → extrun.exe --check で書式を確認してください。
    → 設定ファイルを UTF-8 で保存してください。Shift-JIS は読めません。

 ● メニューは出るが、選んでもアプリが起動しない
    → 起動できなかった場合は、理由を書いたダイアログが出ます。
    → extrun.exe --check で、実行ファイルのパスが見つかっているか
       確認してください。パスは絶対パスで書いてください。
    → .ps1 / .vbs / .js は直接起動できません。powershell.exe -File
       や wscript.exe を経由してください。.bat / .cmd は実行ファイル欄に
       直接書けます（バッチの中では受け取った引数を "%~1" のように
       引用符で囲んでください）。

 ● 選べる項目が少ない
    → 設定ファイルでは拡張子ごとに表示する項目を切り替えています。
       その拡張子に対応する項目が書かれていない可能性があります。
    → 種類の違うファイルを混ぜて選んだときは、そのすべてに当てはまる
       項目だけが表示されます。動画と画像を一緒に選ぶと、動画用の項目も
       画像用の項目も出ません（選んだ項目は選択したファイル全部に対して
       実行されるため、片方にしか使えない項目は出せません）。混ぜても
       出したい項目は [file] や [.mp4 .jpg] のように対象を広げて
       書いてください。

 ● 書いた覚えのない確認ダイアログが出る
    → 一度に 20 個を超えて 1 つずつ起動するときの歯止めです。選び
       間違いでプロセスが大量に並ぶのを防ぐために出しています。
    → 数を変えるか止めるには、設定ファイルの [extrun] に
       confirm-over = 50 のように書きます（off で出なくなります）。

 ● 初回起動時に「Windows によって PC が保護されました」と出る
    → extrun.exe にはコード署名をしていないため、ダウンロードした
       実行ファイルにこの警告が出ることがあります。続行する場合は
       「詳細情報」→「実行」を選んでください。
    → 配布元は上記の GitHub のページだけです。zip が壊れていないかは、
       配布ページに併記した SHA256 と次のコマンドの結果を照合して
       確認できます。

         PowerShell> Get-FileHash .\ダウンロードした.zip -Algorithm SHA256


-----------------------------------------------------------------------
 9. アンインストールと更新
-----------------------------------------------------------------------

 ● 削除する

   1. 「送る」に登録していた場合はショートカットを削除
      （エクスプローラのアドレスバーに shell:sendto と入力）
   2. ExtRun のフォルダごと削除

   ver. 1.1.0 までの .reg で右クリックメニューに登録していた場合は、
   その解除もあわせて行ってください（6 章の末尾）。

   このアプリ自身は、ほかの場所にファイルを作りませんし、
   レジストリの編集もしません。

 ● 更新する

   新しい版の zip を展開して各ファイルを差し替えてください。
   設定ファイル extrun-config.txt は zip に含まれていないので、
   上書きで消える心配はありません。

   同梱の CHANGELOG.md に更新内容が載っています。「変更」の欄だけ
   目を通せば、設定ファイルの見直しが要るかどうかが分かります。
