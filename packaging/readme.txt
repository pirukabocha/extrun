 動作環境
-----------------------------------------------------------------------

 Windows 10（バージョン 1803 以降）/ Windows 11 の 64bit 版

 ※ サンプル設定の「書庫」の項目は Windows 標準の tar.exe を
    使うため、1803 以降が必要です。それ以外の項目は
    もっと古い Windows でも動きます。


-----------------------------------------------------------------------
 導入手順
-----------------------------------------------------------------------

 1) このフォルダごと、好きな場所に置いてください。
    （例: C:\Tools\extrun\ ）
    後から移動すると利用先（ファイラやレジストリ等）からの登録が
    ずれるので、先に置き場所を決めておくことをおすすめします。

 2) extrun-config.sample.txt をコピーして、
    ファイル名を extrun-config.txt に変えてください。

      extrun-config.sample.txt  →  extrun-config.txt

    extrun.exe は、自分と同じフォルダにある
    extrun-config.txt しか読みません。

 3) 任意で下記の「右クリックメニューへの登録」を行ってください。

 サンプル設定は Windows 標準のコマンドだけで動くように作ってあるので、
 この時点でそのまま試せます。
 慣れてきたら、お使いのアプリのパスを書き足してください。
 また、実用的な設定例を extrun-recipes.md にまとめましたので、
 そちらも参考にしてください。


-----------------------------------------------------------------------
 【任意】 右クリックメニューへの登録
-----------------------------------------------------------------------

 このアプリはファイラ等からの利用を想定していますが、
 下記の方法でエクスプローラの右クリックメニューからも利用できます。

 ※ AutoHotkey ユーザー向けに、便利なスクリプトを extrun-recipes.md に
    付録として記載していますので、そちらも参考にして下さい。

 一番簡単なのは「送る」メニューに登録することです：
 1. エクスプローラのアドレスバーに `shell:sendto` と入力
 2. 開いたフォルダに `extrun.exe` のショートカットを置く

 これで、右クリック →「送る」→ ExtRun で
 選択中のファイルを実行できます。
 デスクトップにショートカットを置いて
 ドラッグ＆ドロップする方法も同様に使えます。

 また、レジストリを編集することで、
 右クリックメニュー内に項目として表示することも可能です。
 メモ帳を開いて次の内容を貼り付け、extrun.exe のパスを
 実際の置き場所に書き換えてから、「extrun-add.reg」という
 名前で保存し、ダブルクリックしてください。

 ※ パスの区切りは 「\\」 と 2 個重ねて書きます。
 ※ 管理者権限は不要です（現在のユーザーにだけ登録されます）。

;- - - - - - - - - - ここから - - - - - - - - - -
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Classes\*\shell\ExtRun]
@="ExtRun で開く(&E)"

[HKEY_CURRENT_USER\Software\Classes\*\shell\ExtRun\command]
@="\"C:\\Tools\\extrun\\extrun.exe\" \"%1\""

[HKEY_CURRENT_USER\Software\Classes\Directory\shell\ExtRun]
@="ExtRun で開く(&E)"

[HKEY_CURRENT_USER\Software\Classes\Directory\shell\ExtRun\command]
@="\"C:\\Tools\\extrun\\extrun.exe\" \"%1\""
;- - - - - - - - - - ここまで - - - - - - - - - -

 ★ Windows 11 をお使いの場合

    Windows 11 の右クリックメニューは簡略化されているため、
    追加した項目は「その他のオプションを表示」の中に入ります。
    Shift キーを押しながら右クリックすると直接開けます。

 ★ 登録を解除するには

    上と同じ要領で、次の内容を「extrun-remove.reg」として
    保存してダブルクリックしてください。
    （キー名の前の「-」が削除の指定です）

;- - - - - - - - - - ここから - - - - - - - - - -
Windows Registry Editor Version 5.00

[-HKEY_CURRENT_USER\Software\Classes\*\shell\ExtRun]
[-HKEY_CURRENT_USER\Software\Classes\Directory\shell\ExtRun]
;- - - - - - - - - - ここまで - - - - - - - - - -


-----------------------------------------------------------------------
 使い方
-----------------------------------------------------------------------

 extrun.exe にファイルやフォルダのパスを引数で渡すと
 マウスカーソルの位置にメニューが出ます。
 渡したファイルの種類に応じた項目だけが表示されます。

 複数のファイルやフォルダをまとめて実行することもできます。
 その場合、既定ではファイルごとに 1 つずつアプリが起動します。
 設定側で「+」を付けた項目だけは、すべてのファイルが
 まとめて 1 つのアプリに渡されます。

 このほかに次のオプションがあります。

   extrun.exe --check     設定ファイルを検証する
   extrun.exe --version   バージョンを表示する
   extrun.exe --help      使い方を表示する


-----------------------------------------------------------------------
 設定ファイルの書き方
-----------------------------------------------------------------------

 extrun-config.txt は UTF-8 で保存してください。
 メニューはファイルに書いた順に上から下へと表示されます。

 いちばん短い書き方は、1 行に「名前 | パス」です。

   [.txt]

   メモ帳で開く | C:\Windows\notepad.exe

 [.txt] は「ここから下は .txt が対象」という意味の見出しです。
 パスは絶対パスで書いてください。
 またパスに空白が含まれていても引用符で囲む必要はありません。

 引数を渡したいときは 3 つ目の欄に書きます。
 $p は「選んだファイルのフルパス」に置き換わります。

   VS Code で開く | C:\Program Files\Microsoft VS Code\Code.exe | -n $p

 サブメニュー、区切り線、パスの別名、作業フォルダの指定なども使えます。
 同梱の extrun-config.sample.txt にひととおりの書き方が入っているので、
 まずはそちらを眺めてみてください。
 すべての仕様は extrun-config-format.md にまとめてあります。
 また extrun-recipes.md には実用的な設定例がまとめてあります。


-----------------------------------------------------------------------
 設定を確認する
-----------------------------------------------------------------------

 設定ファイルを書き換えたあと、書式が正しいかを確認できます。
 コマンドプロンプトか PowerShell で、
 extrun.exe のあるフォルダに移動して次を実行してください。

   extrun.exe --check

 書式の誤り、別名の重複や未定義、見つからない実行ファイルなどを
 行番号付きで一覧表示します。


-----------------------------------------------------------------------
 安全にお使いいただくために
-----------------------------------------------------------------------

 ExtRun は、設定ファイルに書かれたコマンドをそのまま実行します。
 設定ファイルは、実行できるスクリプトと同じものだとお考えください。

 ● 出所の分からない extrun-config.txt をそのまま使わないでください。
    中身を読んでから使ってください。

 ● ExtRun のフォルダは、書き込み権限が管理された場所に置いてください。
    （C:\Tools\extrun\ など。誰でも書き込めるフォルダに置くと、
      設定ファイルを他から書き換えられる可能性があります）

 ExtRun 自身は管理者権限を必要とせず、レジストリの編集も、
 設定ファイルの読み込み以外のファイルの読み書きも行いません。


-----------------------------------------------------------------------
 うまくいかないときは
-----------------------------------------------------------------------

 ● レジストリ登録後に右クリックしても項目が出ない
    → Windows 11 では「その他のオプションを表示」の中を
       確認してください（Shift + 右クリックでも開けます）。
    → .reg ファイルに書いた extrun.exe のパスが
       実際の置き場所と合っているか確認してください。

 ● メニューが出ずにエラーが表示される
    → extrun-config.txt が extrun.exe と
       同じフォルダにあるか確認してください
       （extrun-config.sample.txt のままになっていませんか）。
    → extrun.exe --check で書式を確認してください。
    → 設定ファイルが UTF-8 で保存されているか確認してください。
       Shift-JIS では読み込めません。

 ● メニューは出るが、選んでもアプリが起動しない
    → 起動できなかった場合は、理由を書いたダイアログが出ます。
    → extrun.exe --check で、
       実行ファイルのパスが見つかっているか確認してください。
    → パスは絶対パスで書いてください。
    → .bat / .cmd / .ps1 は直接起動できません。
       cmd.exe /c や powershell.exe -File を経由してください。

 ● 初回起動時に「Windows によって PC が保護されました」と出る
    → extrun.exe にはコード署名をしていないため、
       ダウンロードした実行ファイルにこの警告が出ることがあります。
       続行する場合は「詳細情報」→「実行」を選んでください。
    → 配布元は下記の GitHub のページだけです。
       zip が壊れていないかは、配布ページに併記した SHA256 と
       次のコマンドの結果を照合して確認できます。

         PowerShell> Get-FileHash .\ダウンロードした.zip -Algorithm SHA256

 ● 選べる項目が少ない
    → 設定ファイルでは、拡張子ごとに表示する項目を切り替えています。
       その拡張子に対応する項目が書かれていない可能性があります。


-----------------------------------------------------------------------
 アンインストール
-----------------------------------------------------------------------

 1) レジストリの編集を行って右クリックメニューに登録していた場合は、
    上記の「登録を解除するには」を実行する。
 2) 「送る」メニューに登録していた場合はショートカットを削除する。
 3) ExtRun のフォルダごと削除する。

 以上です。
 このアプリ自身は、ほかの場所にファイルを作成しませんし、
 レジストリの編集もしません。


-----------------------------------------------------------------------
 更新するとき
-----------------------------------------------------------------------

 新しい版の zip を展開して、各ファイルを差し替えてください。
 設定ファイルである extrun-config.txt は zip には含まれていませんので、
 上書きで消える心配はありません。
